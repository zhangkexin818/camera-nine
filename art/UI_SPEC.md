# 《第九机位》主界面视觉规范

实现基准：`ui/primary-play-interface_concept_v01.png`。

## 画面层级

1. 单个 21:9 机位画面占主导，不出现九宫格常驻监控墙。
2. CAM、时间码、REC 贴近监视器上边缘。
3. 九机位编号与十秒时间轴进入画面下方控制带。
4. 证据抽屉默认折叠；常态画面内没有答案框，开启检视后只显示跟随玩家的圆形准星。
5. 中央与下中部不放解释文本。
6. 首次进入使用全屏真实画面序幕与底部选择字幕；进入调查后只保留边缘案件问题，不覆盖主画面。

## 色彩与材质 Token

| Token | 值 | 用途 |
|---|---|---|
| `--ink-950` | `#04090a` | 页面与监视器外壳 |
| `--ink-900` | `#071011` | 控制带背景 |
| `--ink-800` | `#0d1919` | 悬停 / 次级表面 |
| `--ivory-100` | `#eee7cf` | 主要文字与选中状态 |
| `--ivory-300` | `#b9b29d` | 次级文字 |
| `--line` | `rgba(207, 202, 178, .24)` | 发丝线 |

材质为消光黑金属、老式播控台刻度和极薄玻璃反射；禁止亮蓝霓虹、厚重毛玻璃、大圆角卡片与面板发光。

## 字体

- 时间码与数值：`IBM Plex Mono`, `Consolas`, `ui-monospace`。
- 中文与控制文本：`Arial Narrow`, `Microsoft YaHei UI`, `Noto Sans CJK SC`, sans-serif。
- CAM 编号使用窄体大写，时间码使用等宽数字；正文不超过 13 px 的视觉密度。

## 组件

- `CameraViewport`：Pixi 画面、交叉淡变、扫描层。
- `FeedChrome`：CAM 编号、地点、时间码、REC。
- `CameraRail`：九个数字机位按钮；09 锁定时仍可见。
- `IncidentTimeline`：十秒刻度、播放头、证据刻度、拖拽输入。
- `TransportControls`：后退一帧、播放/暂停、前进一帧。
- `InspectionLayer`：带真实局部放大的自由检视镜，支持指针、触摸与键盘移动。
- `DiscoveryNotice`：命中线索后居中打开物证近照、时间、名称与说明，必须由玩家确认收录。
- `EvidenceDrawer`：默认折叠，以缩略图展示已发现证据，不解释最终答案。
- `ControlHint`：桌面单行提示；窄屏折叠。
- `StoryPrologue`：五段全屏电影序幕；明确身份与世界规则，身份立场、现场行动和记忆选择进入分支条件。
- `CinematicFocusSequence`：六帧连续动作镜头；玩家手动锁定人物、黑卡、延迟倒影与门禁灯，错误两次后描出辅助焦区，停电后触发一次短促 jump scare。
- `InvestigationBrief`：只提出阶段问题与宽泛思路，不暴露目标机位、时间和物件位置。
- `ArchiveHint`：玩家停滞十秒后或主动调取时出现，给出相关机位与大致秒数；不画证据框、不自动开启检视，移动端覆盖影像而不遮挡控制带。
- `SignalMeter`：提供时间邻近反馈，最高只表达“当前机位的当前秒存在错位”。
- `HypothesisPanel`：核心证据后的推断关卡，先显示已建立联结的双图矛盾回放带，再开放结论；错误选项给出反证。
- `CaseBoard`：证据选择、联结槽和已解封档案都保留图像对照；可选档案明确标识并提供直接追踪缺失画面的入口，主线联结完成后显示“进入最终推断”。
- `TemporalSplicePanel`：四张物证图的时间排序台；选中顺序直接编号，错误两次开放时间码辅助，正确后进入推断。
- `RevelationPanel`：进入 CAM-09 后给出本章发现与下一章悬念，可收起查看完整画面。

## 状态表现

- 选中机位：象牙底 / 深墨字；其他机位为透明底与发丝线。
- 锁定 CAM-09：红色编号、斜线状态口；四条核心证据后变为可选。
- 检视开启：圆形准星跟随玩家；不显示正确点击区轮廓。
- 提示出现：右侧档案条淡入；跟随提示只移动机位与播放头，仍需玩家完成观察。
- 播放：时间轴持续移动；暂停：当前刻度与热点更清晰。
- 机位切换：120–180 ms 交叉淡变；减少动态时取消。

## 响应式

- `>= 900px`：完整九机位横排、完整时间刻度与快捷键提示。
- `600–899px`：机位横向滚动，隐藏地点副标签与快捷键提示。
- `< 600px`：舞台仍保持 21:9；时间轴保留，运输控制与证据按钮分两行；证据抽屉全宽从底部展开。

## 首屏允许文案

- `CAM-01`—`CAM-09`
- 各机位短地点名
- `REC`
- `证据 n/4`
- `核心 n/4`、案件问题与异常强度
- `播放 / 暂停`、`上一帧`、`下一帧`
- `空格 播放/暂停 · ← → 逐帧 · 1–9 切换 · E 开启检视`

常态游戏界面不增加宣传标题、长篇剧情卡或角色对白；真实画面对白和选择只出现在序幕、推断节点与章节揭示中。
