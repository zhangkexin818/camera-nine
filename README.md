# 第九机位

在线游玩：[https://zhangkexin818.github.io/camera-nine/](https://zhangkexin818.github.io/camera-nine/)

《第九机位》是一个可直接在浏览器运行的互动影游竖切片。玩家扮演婚礼纪录片摄影师路野，亲历新娘苏晚在停电后消失，再进入八台封存机位重建最后十秒。

首次进入先给出完整身份：你是 29 岁的婚礼摄影师路野，身处没有公开零层的白礁酒店；档案称你与新娘苏晚今天初见，但烧毁的家庭录像显示十二年前是她牵着七岁的你离开酒店。随后玩家完成身份判断、现场行动、四次手动跟焦与一次现场记忆选择；六帧连续画面会在停电时触发短暂 jump scare，失焦次数也会写入隐藏结局条件。

对白与旁白只以字幕呈现，程序化纯音乐随序幕、调查、异常接近和真相揭示改变。调查不会标出答案位置：玩家需要比较不同机位和秒数，用异常强度接近时间错位，再开启可移动放大镜亲自指出画面矛盾。命中后会弹出带独立物证图、时间与档案说明的信息框。若十秒没有取得进展，“时间回声”会自动给出方向，并可跳到相关机位与大致秒数，但仍由玩家找出具体细节。观察之后还要把两条带图证据放进联结台，验证它们能否同时成立；正确联结会以双图对照解封 B-09 通行卡、零层观察室与第九路信号的旧档案。主线联结完成后还必须把四帧物证按真实发生顺序剪回母带，再进行最终推断。CAM-09 最终提供三个基础结局和两个有条件隐藏结局。

## 启动

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。

第一次点击“确认身份”会解锁浏览器音频。游戏不朗读角色对白或旁白，仅播放无版权依赖的程序化纯音乐；音频按钮会明确显示“播放中”或“未启动”，序幕和回放右上角均可重试或静音。

## 操作

- `Space`：播放 / 暂停
- `←` / `→`：逐帧后退 / 前进
- `1`—`9`：切换机位
- `E`：开启 / 退出画面检视
- `B`：打开证据联结台
- 顶栏“提示”：立即调取下一步方向；停滞十秒也会自动出现
- 检视中点击：指出可疑细节
- `C`：打开 / 关闭证据记录
- `R`：重置十秒片段
- 触屏：使用机位轨、时间轴、检视按钮并点击画面

## 自查

```powershell
npm run check
```

该命令依次校验美术清单与运行时素材、TypeScript、Vitest 单元测试、Playwright 真实浏览器交互与 Axe 无障碍规则，最后执行生产构建。

早期语音实验已移出运行时并保存在忽略构建的 `output/voice-archive`；正式版本不会请求这些文件。

核心文档：

- `GAME_SPEC.md`：玩法、证据链与架构边界
- `WORLD_BIBLE.md`：白礁酒店、角色、时间规则与五结局正史边界
- `art/UI_SPEC.md`：界面视觉、状态与响应式规范
- `QA_REPORT.md`：阶段自查结果与已知边界
- `art/asset-manifest.json`：GPT Image 2 生成资产索引
